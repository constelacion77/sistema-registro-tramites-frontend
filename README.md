# SIRTRA (Frontend)
Sistema para la optimización del proceso en el registro e historico de trámites públicos.

## STACK
Angular 21 (standalone + signals) · Spring Boot 3 · MySQL · JPA/Hibernate

## Arquitectura
Control de acceso con @PreAuthorize por endpoint, filtrado dinámico
mediante DTOs y formularios reactivos con componentes reutilizables.

## Qué mejoraría
Tests de integración y despliegue con Docker.
